PRIVACIDADE

Privacidade com clareza.

Esta página resume o que o aplicativo faz com os dados necessários para funcionar.

O que fica no aparelho

O app salva localmente o idioma, o LOC escolhido e, quando disponíveis, o tipo de leitura e a versão da Bíblia. Essas preferências não exigem uma conta.

O que é enviado ao serviço

Para consultar o lecionário, o app se conecta à API e envia os parâmetros necessários para o LOC, a data e as preferências selecionadas. O tratamento de registros técnicos no servidor depende do operador da API.

O que o app não faz

O app não solicita nome, e-mail, contatos ou localização e não possui anúncios ou cadastro de usuário.
