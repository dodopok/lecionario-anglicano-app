PRIVACIDADE

Privacidade com clareza.

Esta página resume o que o aplicativo faz com os dados necessários para funcionar.

O que fica no aparelho

O app salva localmente o idioma, o LOC escolhido e, quando disponíveis, o tipo de leitura e a versão da Bíblia. Essas preferências não exigem uma conta.

O que é enviado ao serviço

Para consultar o lecionário, o app se conecta à API por HTTPS e envia o X-App-Internal-Id, o LOC, a data e, quando disponíveis, o tipo de leitura e a versão da Bíblia. A API não armazena logs identificáveis dessas requisições.

O que o app não faz

O app não solicita nome, e-mail, contatos ou localização e não possui anúncios ou cadastro de usuário.

Registros operacionais

New Relic e Sentry recebem registros operacionais não identificáveis para monitoramento e diagnóstico. Esses registros não são usados pelo serviço para identificar usuários.

Responsável e solicitações

O responsável pelo aplicativo é Douglas Araujo. Não há conta nem perfil remoto para excluir; as preferências ficam no aparelho e são removidas quando o app é desinstalado. Para dúvidas ou solicitações relacionadas à privacidade: dev@dodopok.dev.

Dúvidas
